# Мандельброт как замер железа (CPU vs GPU)

Побочный, но наглядный бенчмарк: один и тот же расчёт множества Мандельброта на
разном железе. Метрика — время на фиксированную нагрузку.

**Нагрузка:** 6000×4000 пикселей, 500 итераций, тот же torch-код на всех GPU.

## Результаты

| Железо | Время | Throughput | Ускорение к CPU |
|---|---|---|---|
| CPU сервера (numpy, 8 ядер Xeon) | 162 800 мс | — | 1× |
| **RTX 3070 Laptop** (8 ГБ) | **5 298 мс** | 2.3 млрд итер-пикс/с | **31×** |
| **RTX 4090** (24 ГБ) | **1 894 мс** | 6.3 млрд итер-пикс/с | **86×** |
| H100 (80 ГБ) | — | — | (todo) |

- GPU рвёт CPU на порядок(и) — задача идеально параллельная.
- 4090 быстрее 3070-ноута в **2.8×** — по разнице FP32 и пропускной способности памяти.

## Нюанс про H100

H100 **не факт что сильно быстрее 4090** на этой задаче: это **чистый FP32-растр**,
а H100 заточен под FP16/BF16/тензорные операции (ИИ). У 4090 даже больше FP32-терафлопс;
H100 выигрывает памятью (3.35 ТБ/с), но разрыв будет скромным. Мораль: «H100 = всегда
быстрее» — миф, зависит от типа нагрузки.

## Запуск

```bash
# CPU (numpy + pillow):
python mandelbrot_cpu.py                 # -> /tmp/mandelbrot.png

# GPU (torch, CUDA). Если torch нет:
#   pip install torch --index-url https://download.pytorch.org/whl/cu121
python mandelbrot_gpu.py                 # печатает время + GPU + сохраняет png
```

Гладкая (smooth) циклическая раскраска; внутри множества — чёрный.
