# Локальные чатовые модели

Отдельно от кодинга и агентов — модели для **разговора/ассистента** локально на
RTX 3070 8 ГБ. Другой профиль требований: важны связность диалога, русский,
следование инструкциям и **время до первого ответа**, а не только код.

## Что брать под чат на 8 ГБ (из данных бенчмарка)

| Модель | Профиль для чата | Ждать ответ |
|---|---|---|
| **gemma3:12b** | лучший баланс качество/скорость, хороший русский | ~24 с |
| **qwen2.5:7b** | мгновенный отклик, живой диалог | ~5 с |
| **llama3.1:8b** | ровный ассистент, хорошо следует инструкциям | быстрый |
| **mistral-nemo:12b** | длинный контекст, аккуратный тон | средний |
| gpt-oss:20b | максимум качества, но 57% на CPU → ~2.5 мин | медленный |

Для чата **скорость до ответа критичнее**, чем для «спросил и ушёл»: `qwen2.5:7b`
и `gemma3:12b` — практичный выбор.

## Чат без цензуры

Если нужен неограниченный **разговор** (а не код):
- `llama31-abliterated` (уже локально) — general-модель со снятыми отказами.
- Серии `dolphin-*` и `*-abliterated` general-моделей (не кодерских) на 7–12B.

Оговорка та же, что в ветке `uncensored-models`: аблитерация просаживает качество
и повышает галлюцинации. Для чата это заметнее, чем для кода.

## Как запускать чат с UI (не терминал)

Для нормального «чата» удобнее GUI. **Open WebUI** — веб-чат поверх Ollama:

```bash
docker run -d --name open-webui -p 3000:8080 \
  --add-host host.docker.internal:host-gateway \
  -e OLLAMA_BASE_URL=http://host.docker.internal:11434 \
  -v open-webui:/app/backend/data \
  ghcr.io/open-webui/open-webui:main
# затем http://localhost:3000 — выбираешь модель, общаешься
```

Это **чат, не агент** — файлы/команды не трогает, зато удобный интерфейс, история,
переключение моделей, системные промпты. Ровно то, что нужно для «поговорить».

## Чем это отличается от других веток

- `main` / `cloud-free-models` — бенчмарк 32 задачи (код+логика).
- `uncensored-models` — цена аблитерации на тех же задачах.
- `local-ai-agents` / `server-agents-research` — модели как **агенты** (действия).
- **`local-chat-models` (эта)** — модели как **собеседник** (диалог, UI, скорость
  отклика).

## Что можно померить отдельно для чата
- **Время до первого токена** (не общий tok/s) — субъективная «живость».
- **Русский** в свободном диалоге (а не только в задачах).
- **Удержание контекста** в длинной беседе.
- **Тон/отказы** general vs abliterated в разговоре.
