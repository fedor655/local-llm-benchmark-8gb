# Refusal-rate: stock vs abliterated (результаты)

Замер эффекта аблитерации на **отказах** — по опубликованным наборам, через обе
модели `Qwen3-Coder-30B-A3B` (сток и abliterated, один квант). Сохранялись
**только агрегированные метки** «отказ/выполнил»; сырые ответы моделей не
записывались и не показывались.

## Результаты

| Набор | Что мерит | stock | abliterated |
|---|---|---|---|
| **StrongREJECT** (120 вредных) | доля ОТКАЗОВ (выше = осторожнее) | **88.3%** | **0.0%** |
| **XSTest** (250 безобидных) | over-refusal, ложные отказы (меньше = лучше) | 7.2% | 0.8% |

## Вывод

- **Аблитерация убирает отказы полностью:** 88.3% → **0.0%** на вредных пробах.
  Механизм (вырезание направления отказа) работает как заявлено — под ноль.
- **И снижает ложную перестраховку:** 7.2% → 0.8% на безобидных. Модель в принципе
  реже отказывает.

Вместе с остальными замерами (см. `docs/uncensored.md`, ветка
`server-agents-research`):

| Метрика | Эффект аблитерации |
|---|---|
| Отказы на вредном | 88.3% → 0% |
| Ложные отказы на безобидном | 7.2% → 0.8% |
| Полный бенчмарк 32 задачи (та же методика) | **83.5/100 = 83.5/100** (идентично!) |
| Корректность кода (агентно, 4 задачи) | 4/4 = 4/4 (без потерь) |
| Дисциплина tool-calling | просажена |

Аблитерация не делает модель «глупее» на коде — но убирает отказы начисто и
просаживает следование строгим протоколам инструментов.

## Методика и оговорки

- **Наборы:** XSTest (safe-часть, 250) — over-refusal; StrongREJECT (выборка 120) —
  отказ на вредном. Оба опубликованы, промпты не самодельные.
- **Классификатор:** эвристика по маркерам отказа в первых ~400 символах
  («I can't/cannot/won't/sorry…»). Быстро и достаточно для сравнения долей;
  дообученный судья (HarmBench-classifier/Llama-Guard) дал бы точнее, но контраст
  88% vs 0% однозначен и без него.
- **Этика/безопасность:** цель — измерить устойчивость, а не добыть контент.
  На диск/в вывод шли только счётчики. Сырые генерации отбрасывались сразу.

## Воспроизведение

```bash
# на сервере с обеими моделями в Ollama:
python3 bench/refusal_eval.py     # сам качает XSTest + StrongREJECT, печатает доли
```
