рабочей станции, поддержка более 20 MoE-моделей.

## Системные требования

Из `docs/install.md` репозитория:

- **ОС:** Linux x86_64. Windows и WSL2 указаны как неподдерживаемые.
- **Драйвер:** r580 или новее.
- **CUDA:** 13, с `nvcc` в PATH — ядра компилируются JIT при первом запуске.
- **Python:** 3.10+, рекомендуется `uv`.
- Минимумы по VRAM и системной RAM в документации не заданы.

В README репозитория дополнительно упомянуто десктопное приложение для Windows
и Linux на flashml.ai. Это бинарник со стороннего сайта, не с GitHub; мы его
не скачивали.

Поддерживаемые GPU по README — NVIDIA RTX 30, 40 и 50. RTX 3070 Laptop
(Ampere, compute capability 8.6) в этот список попадает.

## Заявленная производительность

Три конфигурации из статьи. Это результаты авторов, не наши замеры.

| Железо | Системная RAM | Модель | Скорость |
|---|---|---|---|
| RTX 4060 Laptop, 8 ГБ | 32 ГиБ | Qwen3.6-35B-A3B NVFP4 | 39.3 tok/s |
| RTX 5090, 32 ГБ | 192 ГиБ | DeepSeek-V4-Flash | 22–25 tok/s |
| RTX PRO 6000, 96 ГБ | 512 ГиБ | GLM-5.2 | 14.9 tok/s против 7.3 у llama.cpp |

**Ключевая деталь, которая теряется в пересказах: 8 ГБ VRAM в первой строке
сопровождаются 32 ГиБ системной памяти.** Полный пул экспертов держится в
host RAM — это условие работы метода, а не деталь стенда.

Обзор с разбором конфигураций:
[wavect.io](https://wavect.io/blog/freetoken-ai-inference-engine-review/) —
там же оговорка, что на результат влияют архитектура модели, квантование,
контекст, объём и пропускная способность host RAM и поколение PCIe.

## Расчёт, почему 35B не влезает

Qwen3.6-35B-A3B в NVFP4, ~4.25 бита на параметр:

```
35e9 × 4.25 / 8 ≈ 18.6 ГБ   только веса
```

Доступно: 8 ГБ VRAM + ~11 ГБ RAM (16 минус расход Windows) ≈ 19 ГБ. На KV-кэш,
активации и контекст не остаётся ничего. Со стримингом с SSD запуск возможен,
но выигрыш метода теряется — он весь построен на том, что эксперты в RAM.

## Расчёт потолка для gpt-oss:20b

Модель MoE: 21B всего, 3.6B активных, MXFP4, 13.8 ГБ. В список поддерживаемых
FreeToken входит. В нашу память помещается.

```
3.6e9 × 0.5 байта ≈ 1.8 ГБ трафика на токен
DDR4-3200, два канала: 51.2 ГБ/с теоретических, 35–40 реальных
→ порядка 15–30 tok/s
```

Текущий результат на Ollama — 6.7 tok/s при 57 % слоёв на процессоре. Ожидаемый
выигрыш в 2–4 раза согласуется с заявкой авторов про 2–4× против Ollama.

Повторим: это оценка по пропускной способности, а не измерение.

## Рынок памяти

Курс ЦБ РФ на 20.08.2026 — **85.13 ₽/$**. По нему считаны все рублёвые оценки.

Комплект 32 ГБ (2×16) DDR4-3200 SO-DIMM, розница:

| Период | Цена |
|---|---|
| Начало 2024 | $67 |
| Октябрь 2025 | $75 |
| Январь 2026 | $165 |
| Февраль 2026 | $195 |
| Август 2026 | $297 |

Комплект 2×32 ГБ, который нужен для апгрейда, — порядка $700, с российской
наценкой 15–20 % это около 65 000 ₽.

Что происходит с рынком:

- Контрактные цены на DRAM выросли на 90–95 % за квартал, PC DRAM — на
  105–110 % ([TrendForce через accio](https://www.accio.com/business/dram_price_trend)).
- DDR4 в Q3 2026 прибавляет более 50 %; отдельные SKU выросли более чем на
  2200 % от минимумов 2024 года
  ([wccftech](https://wccftech.com/memory-shortages-drive-ddr4-prices-over-50-in-q3-2026-ddr3-also-impacted-by-higher-costs/)).
- Причина — переброс мощностей Samsung, SK Hynix и Micron с потребительской
  DRAM на HBM для ИИ-ускорителей.
- Micron выпустил финальные EOL-уведомления по DDR4; к концу 2026 мощности
  DDR4 ожидаются на уровне 20–25 % от 2024 года
  ([microchipusa](https://www.microchipusa.com/industry-news/samsung-and-sk-hynix-extend-ddr4-lifecycles)).
- В России модули стоят на 15–20 % дороже мировых значений из-за курса и
  логистики ([vbr.ru](https://www.vbr.ru/sovety/help/tekhnologii/pocemy-ozy-podorozhala-prognoz-cen/)).

## Что осталось непроверенным

- FreeToken не устанавливался и не запускался. Все цифры по нему — либо заявки
  авторов, либо наши расчёты по пропускной способности.
- Рублёвые цены не сняты с прилавка: DNS отдал 401 при попытке прочитать
  каталог. Оценка выведена из долларовой розницы и известной наценки —
  перед покупкой проверять руками.
- Заработает ли сборка на Ampere и на WSL2 вопреки документации — неизвестно.
  Ядра компилируются JIT, так что проверяется только запуском.
- Модели Ollama с прогонов бенчмарка удалены, кэш пуст. Для A/B с `gpt-oss:20b`
  их придётся качать заново (13.8 ГБ).
