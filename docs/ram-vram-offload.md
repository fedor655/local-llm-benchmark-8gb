# Инференс с офлоадом в RAM вдобавок к VRAM (FreeToken и аналоги)

Движок [FlashML-org/FreeToken](https://github.com/FlashML-org/FreeToken):
«edge-native MoE serving engine» — запуск больших MoE-моделей на потребительском
железе, распределяя нагрузку между GPU, RAM, CPU и PCIe.

## Реальность проекта — да

- ~8.6k звёзд, 749 форков, Apache-2.0, ~40 коммитов.
- Есть [arXiv-статья](https://arxiv.org/abs/2608.16157) («Bandwidth-Adaptive
  Execution»), десктоп-приложение, Slack/Discord.
- Поддерживаемые модели (DeepSeek-V4-Flash, GLM-5.2, Qwen3.6-35B-A3B, gpt-oss,
  Gemma-4 и др.) — **реальные**, вышли в 2026. Это не фейк.

> Дисклеймер к самому себе: первично я заподозрил выдуманные модели — ошибка от
> порога знаний (январь 2026). Модели просто новее. Проект легитимный.

## Почему заявленные цифры правдоподобны (но с оговоркой)

Ключ — **MoE с малым числом активных параметров**:
- `Qwen3.6-35B-A3B` = 35B всего, но **3B активных** на токен.
- На токен считается мало → узкое место не вычисления, а **вес экспертов**.

FreeToken (как ktransformers / PowerInfer / MoE-offload в llama.cpp) держит
активный путь на GPU, а экспертов **стримит/кеширует** из RAM по PCIe, с
bandwidth-adaptive планировщиком. Отсюда:
- **39 ток/с для 35B-A3B на 8 ГБ RTX 4060** — правдоподобно (активных всего 3B).
- **22–25 ток/с для 284B DeepSeek-V4-Flash на RTX 5090 (32 ГБ)** — эффектно, но
  **промо умалчивает про RAM**: чтобы держать эксперты 284B, нужны **десятки–сотни
  ГБ системной памяти** + быстрый PCIe. Число — best-case.

## Что проверять, прежде чем верить

1. **Требования к RAM** — headline про VRAM ничего не значит без объёма RAM.
2. **tok/s vs время-до-ответа** — как в основном бенчмарке (см. `README`): быстрый
   tok/s не спасает, если модель «думает» тысячи токенов.
3. **Реальный, а не cherry-picked промпт** — прогнать те же 32 задачи.

## План теста на нашем железе (RTX 3070 8 ГБ)

Честное сравнение на **одной и той же MoE-модели**, влезающей по логике FreeToken:

```bash
# кандидат: Qwen3-Coder-30B-A3B (3B активных) или Qwen3.6-35B-A3B
# 1) базлайн — llama.cpp/Ollama с MoE-офлоадом:
ollama run <moe-model>            # замер tok/s + время до ответа + RAM
# 2) FreeToken по их install.md:
#    (следовать github.com/FlashML-org/FreeToken/blob/main/docs/install.md)
freetoken serve <moe-model>       # тот же замер
# 3) сравнить: tok/s, время до готового ответа, пиковая RAM, качество на 32 задачах
```

Метрики те же, что в репозитории: **балл на 32 задачах + время до ответа + память**.
Тогда «революция» станет цифрой, а не лозунгом.
