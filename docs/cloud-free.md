# Бесплатные облачные модели: те же 32 задачи, замеры и ограничения

Третий вариант рядом с «купить память» и «арендовать GPU» — не платить вообще
и брать бесплатные тиры облачных провайдеров. Прогон выполнен 26 августа 2026
года по той же методике, что и локальный: те же 32 задачи, те же проверки
исполнением, те же параметры генерации.

Итог одной строкой: **по качеству облако выигрывает у локального железа
с разгромным счётом, но упирается в лимиты, которые делают его непригодным
для агентов и для долгой работы.**

## Как это измерялось

Добавлен [`bench/cloud.py`](../bench/cloud.py). Он подменяет только транспорт —
вместо Ollama HTTP API идёт OpenAI-совместимый вызов к провайдеру. Разбор
ответа, исполнение кода, чекеры и формула балла берутся из `bench.py` без
изменений. Локальный путь не тронут.

Перед прогоном в том же окружении выполнен `bench/validate_tasks.py` —
0 проблем, эталонные решения проходят, `node` для JS-задач на месте.

Параметры совпадают с локальными: `temperature = 0.2`, `top_p = 0.9`.
`num_predict` передаётся как `max_tokens`. `num_ctx` неприменим — контекст
задаёт провайдер.

### Чего сравнивать нельзя

**`tok/s` у облачных строк — не то же самое, что у локальных.** Ollama
сообщает чистую скорость генерации (`eval_count / eval_duration`). Облако
такого поля не отдаёт, поэтому здесь это сквозная величина: выходные токены,
делённые на полное время запроса вместе с сетью и очередью провайдера.
Значение занижено и сравнивать его с локальным нельзя.

Сравнимы: **балл, доля решённых задач и время ожидания ответа**.

### Что сделано с лимитами

Бесплатные тиры отдают 429 постоянно, и без обработки прогон обрывался на
втором запросе. Ожидание встроено в `cloud_chat`, с двумя особенностями,
которых нет в локальном мире:

- **Groq сообщает превышение лимита кодом 413, а не 429.** В теле стоит
  `"code": "rate_limit_exceeded"`. Оба кода трактуются как лимит.
- Срок ожидания провайдеры кладут в разные места: Groq — в текст сообщения
  (`try again in 22.1s`), остальные — в заголовок `Retry-After`. Разбираются
  оба, дальше экспоненциальный откат.

**Время ожидания лимита не входит в `wall`.** Иначе бенчмарк измерял бы
щедрость тарифа, а не скорость модели. Оно пишется отдельным полем
`rate_limit_wait_s`.

## Ограничения, из-за которых это не заменяет локальный запуск

### Лимиты, снятые с живых ответов

| Провайдер | Что вернул | Практический смысл |
|---|---|---|
| **Cerebras** | `HTTP 402 Payment required to access this resource` | Бесплатного доступа к API нет вообще. Ключ выдаётся, но не работает. |
| **OpenRouter** | `HTTP 429 free-models-per-day`, `X-RateLimit-Limit: 50` | **50 запросов в сутки.** Две модели по 32 задачи их исчерпали, третья (`glm-5.2:free`) до прогона не дожила. |
| **Groq** | `HTTP 413 ... TPM: Limit 8000, Requested 48121` | **8000 токенов в минуту.** Хватает на короткие задачи, не хватает на агентов. |

### Почему это не годится для агентных инструментов

Замер сделан отдельно: Claude Code отправляет **48 121 токен в одном запросе** —
системный промпт плюс определения инструментов. Это в шесть раз больше всего
минутного бюджета Groq. Не «медленно», а невозможно в принципе.

Проверка одним запросом такого размера:

| Модель | Ответ |
|---|---|
| `groq/openai/gpt-oss-120b` | 413, лимит 8000/мин |
| `cerebras/gpt-oss-120b` | 402 Payment Required |
| `openrouter/z-ai/glm-5.2:free` | 429 |
| `openrouter/nvidia/nemotron-3-ultra-550b:free` | **200**, принял 48 016 токенов |
| `openrouter/minimax/minimax-m3:free` | **200**, принял 48 163 токена |

То есть коротким задачам бенчмарка хватает почти всех, а агентной нагрузке —
только OpenRouter, и то в пределах 50 запросов в сутки.

### Данные уходят третьей стороне

Локальная модель не отправляет код никуда. Облачная отправляет весь контекст
провайдеру. У части бесплатных тиров это прямо оплачивается данными —
например, Google AI Studio оговаривает, что на бесплатном тарифе данные могут
использоваться для улучшения моделей вне UK/CH/EEA/EU.

Для учебных задач и своих пет-проектов это неважно. Для рабочего кода
под NDA — исключает вариант целиком.

### Воспроизводимости нет

Локальная модель с фиксированным сидом воспроизводима и не исчезнет. Облачная
может быть в любой момент переименована, ограничена или убрана, а версия
за вывеской `:free` меняется без предупреждения. Числа выше — снимок
на 26 августа 2026 года.

## Что осталось непроверенным

- `openrouter/z-ai/glm-5.2:free` не прогнан: суточный лимит в 50 запросов
  закончился раньше. Его балл неизвестен.
- Прогон по каждой модели одиночный. Разброс между повторами не измерен —
  при `temperature = 0.2` он невелик, но не нулевой.
- Не проверялось, отличается ли модель за вывеской `:free` у OpenRouter
  от платной версии той же модели квантованием или маршрутизацией.
- Cerebras оценён только по коду ответа 402; возможно, доступ открывается
  после верификации, которую мы не проходили.

## Как повторить

```bash
export GROQ_API_KEY=...
export OPENROUTER_API_KEY=...

python bench/cloud.py --list
python bench/cloud.py --models groq/openai/gpt-oss-120b --resume
```

Ключи можно не держать в окружении, а положить в файл и указать его
через `BENCH_ENV_FILE`. Пауза между запросами регулируется
`BENCH_THROTTLE_S` (по умолчанию 2 с), число попыток при лимите —
`BENCH_MAX_429_RETRIES`.
