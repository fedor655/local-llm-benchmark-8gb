# Исследование локальных ИИ-агентов на арендованном GPU

Продолжение бенчмарка: та же методология, но модель работает **как агент**
(читает-правит-запускает), а не отвечает одним сообщением.

## Стенд

- **GPU:** аренда RTX 4090 24 ГБ (immers.cloud, ~85 ₽/ч), Ubuntu 24.04 + CUDA.
- **Движок:** Ollama 0.33, модель целиком в VRAM (100% GPU), контекст 32K.
- **Модели** (один квантайзер/квант, отличие только в цензуре):
  - `coder-abliterated` — `Huihui-Qwen3-Coder-30B-A3B-Instruct-abliterated` (i1-Q4_K_M)
  - `coder-stock` — `Qwen3-Coder-30B-A3B-Instruct` (i1-Q4_K_M)
- **Агент-клиенты:** Aider (CLI) и OpenHands (веб-UI + Docker-песочница).

## Вывод 1 — размер решает: 30B держит протокол, 7B нет

На локальной 3070 (см. ветку `local-ai-agents`) 7B-abliterated в роли агента
**не выдал ни одного валидного шага** протокола за 10 итераций. Та же обвязка,
но 30B на сервере — **следует протоколу** `RUN:`/`DONE:` со всех попыток, а
через Aider применяет правки и проходит проверку исполнением.

Значит провал 7B — это про **размер** (дисциплина инструкций растёт с масштабом),
а не только про аблитерацию.

## Вывод 2 — цена аблитерации видна на дисциплине инструментов

Наблюдения на 30B-abliterated в OpenHands (CodeActAgent):

- **Пропуск обязательного параметра tool-call.** OpenHands требует поле
  `security_risk` в каждом `execute_bash`. Модель **раз за разом его забывала**
  (~десяток `Agent encountered an error: Missing required parameters ...
  {'security_risk'}`), прежде чем выправиться.
- **Переусердствование на расплывчатом вводе.** На «привет» агент не поздоровался,
  а **построил Flask-приложение**, отдающее «привет» на `/`. Слабое следование
  инструкциям → додумывает задачу.

Оба симптома — ожидаемая цена снятия направления отказа: первым страдает
структурированный вывод и tool-calling. Проверяется сравнением со `coder-stock`
на тех же задачах.

## Вывод 3 — канал имеет значение: HTTP API, не TTY

Три отдельных сбоя маскировались под «модель тупит»:

1. `ollama run > file` вставляет перенос строки посреди слова (форматирование под
   ширину терминала) → битый Python. **Звать модель по HTTP API**, не через TTY.
2. Под Git Bash Aider падал с `UnicodeEncodeError` (cp1251 vs символ прогресс-бара).
   Лечение: `PYTHONUTF8=1` + `--no-pretty`, либо запуск в cmd/PowerShell.
3. `bash` в Windows PATH = сломанный WSL-лаунчер (`System32\bash.exe`); брать
   git-bash явно.

## Вывод 4 — тяжёлый рантайм OpenHands не вывозит сетевой том

Симптом: агент вис на «Starting runtime… (1-2 minutes)», app-контейнер сыпал
`httpx.ReadError: Connection reset by peer` на `check_if_alive`.

Диагностика (по шагам):
- Порты песочницы **проброшены** (тест nginx на том же механизме давал HTTP 200).
- Action-сервер **не отвечал даже на `localhost` изнутри своего контейнера**.
- Процесс `action_execution_server` **жив**, но логи виснут на
  `Browser env started`, а HTTP-порт биндится **последней строкой** — после
  инициализации плагинов.

**Корень:** синхронная инициализация тяжёлых плагинов **jupyter + vscode**
(kernel-gateway, code-server) не завершается на **сетевом SSD с x3-репликацией** —
порт не биндится, app получает reset. Не модель, не сеть, не фаервол.

**Фикс** (патч `openhands/runtime/base.py`, оставить только AgentSkills):

```python
# после self.plugins.append(VSCodeRequirement())
self.plugins = [p for p in self.plugins
                if type(p).__name__ == 'AgentSkillsRequirement']
```

После патча action-сервер поднимается за ~40 с, агент работает: подключается к
песочнице, вызывает модель (GPU 100%), пишет и запускает файлы. Цена: нет
IPython-исполнения и вкладки VS Code; агент работает через bash + правку файлов.

## Методика сравнения stock vs abliterated

1. **Качество/дисциплина** — 32 задачи бенчмарка через агента, проверка
   исполнением unit-тестов (как в основном репозитории). Дельта прохождения и
   число tool-call ошибок = цена аблитерации.
2. **Отказы (refusal-rate)** — только на **опубликованных** наборах (AdvBench,
   StrongREJECT, XSTest), классификатор ставит метку «отказ/выполнил», **сырой
   вывод не сохраняется**. Разница долей отказов = эффект снятия цензуры.
   Ручная генерация вредного контента — вне рамок (меряем устойчивость, не добываем).
