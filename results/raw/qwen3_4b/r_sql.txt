Хорошо, давай разберёмся с этим вопросом. У нас есть таблица orders с колонками id, user_id, amount и status. Нужно найти user_id, у которых суммарная amount по строкам с status='paid' больше 1000. Вопрос в том, какое ключевое слово SQL используется для фильтрации по результату агрегатной функции.

Сначала вспомню, что в SQL для агрегатных функций, например, SUM, обычно используется GROUP BY. Но здесь вопрос не о группировке, а о фильтрации результатов агрегатной функции. То есть, после вычисления суммы по группам, нужно выбрать те группы, где сумма превышает 1:1000.

Например, сначала группируем по user_id, суммируем amount для status='paid', а потом фильтруем те user_id, где эта сумма > 1000. В этом случае, ключевое слово для фильтрации по результату агрегатной функции — это WHERE. Но подожди, нет, WHERE используется для фильтрации строк до агрегации. А здесь после агрегации, то есть в группе, нужно проверить условие на сумму.

В SQL, когда мы используем GROUP BY, агрегатные функции применяются к каждой группе, и затем, чтобы отфильтровать группы, мы используем WHERE. Но здесь важно, что условие на агрегатную функцию применяется после группировки. То есть, в запросе будет:

SELECT user_id
FROM orders
WHERE status = 'paid'
GROUP BY user_id
HAVING SUM(amount) > 1000

Тут ключевое слово для фильтрации по результату агрегатной функции — это HAVING. Потому что WHERE используется для фильтрации исходных строк, а HAVING применяется к агрегатным результатам после группировки.

Да, точно. В данном случае, после группировки по user_id, мы суммируем amount для status='paid', и затем фильтруем группы, где сумма больше 1000. Для этого используется HAVING. Поэтому ответ — HAVING.

Проверю ещё раз. Если бы было WHERE, то условие было бы на исходные строки, но здесь нужно проверить сумму, которая уже агрегирована. Значит, HAVING.
