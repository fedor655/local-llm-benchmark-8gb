Хорошо, мне нужно определить, какой протокол используется для передачи гипертекста в интернете. Пользователь просит ответить одним словом, заглавными буквами, без точки и других символов.

Сначала вспомню, что гипертекст обычно связан с веб-страницами. В интернете основной протокол для передачи гипертекста — это HTTP. Но есть и HTTPS, который безопасный вариант. Однако вопрос про передачу гипертекста, а не безопасную. В учебниках обычно говорят, что HTTP используется для передачи гипертекста. 

Проверю: HTTP — HyperText Transfer Protocol. Да, это правильный ответ. HTTPS — это шифрованный HTTP, но основной протокол для гипертекста — HTTP. Нужно убедиться, что ответ именно HTTP, без точки и заглавными буквами. Значит, ответ будет HTTP.

Подожду, может быть есть другие протоколы? Например, FTP для файлов, но гипертекст — это HTML, который передаётся через HTTP. Да, точно HTTP. Всё верно.
