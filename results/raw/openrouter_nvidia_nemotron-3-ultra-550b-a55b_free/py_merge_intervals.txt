The user wants a Python function `merge_intervals` that takes a list of intervals (list of lists of ints) and returns a new list of merged intervals.
Constraints:
1. Merge overlapping and touching intervals (e.g., [1,4] and [4,5] -> [1,5]).
2. Return sorted by left boundary.
3. Do not modify the input list.
4. Output must be a single code block with Python code, no explanations, no tests.
<<<END THINKING>>>

```python
def merge_intervals(intervals: list[list[int]]) -> list[list[int]]:
    if not intervals:
        return []
    
    sorted_intervals = sorted(intervals, key=lambda x: x[0])
    merged = [sorted_intervals[0][:]]
    
    for current in sorted_intervals[1:]:
        last = merged[-1]
        if current[0] <= last[1]:
            last[1] = max(last[1], current[1])
        else:
            merged.append(current[:])
            
    return merged
```
