Хорошо, пользователь спрашивает о ключевом слове SQL для фильтрации по результату агрегатной функции. Нужно вспомнить, как работает группировка и фильтрация в SQL.

В задаче нужно найти user_id, где сумма amount для статуса 'paid' превышает 1000. Для этого сначала нужно сгруппировать данные по user_id и посчитать сумму. Но как отфильтровать те группы, где сумма больше 1000?

Помню, что после группировки с помощью GROUP BY можно использовать HAVING. Это условие применяется к агрегатным функциям, в отличие от WHERE, которое работает с строками перед группировкой. 

Проверяю: если использовать WHERE, то оно не сможет отфильтровать по сумме, так как сумма вычисляется после группировки. Поэтому правильный ответ — HAVING. 

Нужно убедиться, что нет других возможных вариантов. Например, нет ключевого слова типа FILTER, хотя оно есть в некоторых стандартах, но в стандартном SQL для этого используется HAVING. 

Таким образом, правильный ответ — HAVING.
