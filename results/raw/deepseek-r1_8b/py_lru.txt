Мы создадим класс LRUCache с использованием двусвязного списка и хеш-таблицы (словаря).
 Для отслеживания порядка использования будем использовать двусвязный список, где каждый узел содержит ключ и значение.
 Также будем использовать словарь для быстрого поиска узла по ключу.

 Операции:
   - __init__: инициализирует capacity и пустой список (хеш-таблицу) и пустой двусвязный список.
   - get: проверяет наличие ключа в словаре. Если есть, возвращает значение и перемещает узел в конец списка (чтобы он считался недавно использованным). Если нет, возвращает -1.
   - put: добавляет или обновляет пару ключ-значение. Если ключ уже есть, обновляем значение и перемещаем узел в конец списка. Если нет, добавляем новый узел в конец списка и в словарь. Если кэш заполнен, удаляем самый старый (начало списка) и обновляем словарь.

 Реализуем двусвязный список с возможностью быстрого удаления и добавления в начало и конец.

 Узел (двойной связанный список):
   - key
   - value
   - prev
   - next

 Методы для двусвязного списка (внутри класса LRUCache):
   - _add_node(node): добавляет узел в конец списка (последним).
   - _remove_node(node): удаляет узел из списка.
   - _move_to_end(node): перемещает узел в конец списка.

 Также будем хранить голову и хвост списка.

 Однако, чтобы не усложнять, мы можем использовать только хвост и голову, и при добавлении в конец, а при удалении из начала.

 Но для эффективности будем использовать:
   - head и tail указатели на начало и конец списка.

 При добавлении нового элемента в конец (как самый недавно использованный) мы добавляем после tail (или tail.next, но обычно tail указывает на последний узел).
 При удалении самого старого (из начала) удаляем узел после head (или head.next).

 Однако, стандартный подход: двусвязный список с head и tail, и мы всегда добавляем в конец (после tail) и удаляем из начала (перед head).

 Но в нашем случае, при добавлении нового элемента мы добавляем в конец (последним) и при удалении удаляем первый (старейший).

 Также, когда мы берем элемент из кэша (get), мы перемещаем его в конец (последний) и при обновлении (put) также перемещаем в конец.

   class Node:
        __slots__ = ('key', 'value', 'prev', 'next')

   class LRUCache:
        def __init__(self, capacity: int):
            self.capacity = capacity
            self.cache = {}  # словарь ключ: узел
            self.head = None  # голова списка (для удаления старых)
            self.tail = None  # хвост списка (для добавления новых)
            self.size = 0

        def _add_node(self, node):
            # добавляем узел в конец списка
            if self.tail is None:
                self.head = node
                self.tail = node
            else:
                self.tail.next = node
                node.prev = self.tail
                self.tail = node
            self.size += 1

        def _remove_node(self, node):
            # удаляем узел из списка
            if node.prev:
                node.prev.next = node.next
            else:
                self.head = node.next

            if node.next:
                node.next.prev = node.prev
            else:
                self.tail = node.prev

            self.size -= 1

        def _move_to_end(self, node):
            # перемещаем узел в конец списка
            self._remove_node(node)
            self._add_node(node)

        def get(self, key):
            if key not in self.cache:
                return -1
            node = self.cache[key]
            # Если узел не в конце, то перемещаем его в конец
            if node != self.tail:
                self._move_to_end(node)
            return node.value

        def put(self, key, value):
            node = None
            if key in self.cache:
                node = self.cache[key]
                node.value = value
                # Если узел не в конце, перемещаем его в конец
                if node != self->tail:
                    self._move_to_end(node)
            else:
                node = Node(key, value)
                self.cache[key] = node
                self._add_node(node)
                if self.size > self.capacity:
                    # Удаляем первый узел (старейший)
                    oldest = self.head
                    self._remove_node(oldest)
                    del self.cache[oldest.key]
